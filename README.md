## Descripción general

Este repositorio reúne varios talleres de Angular para construir un catálogo de productos con:

- consumo de API REST
- servicios e inyección de dependencias
- estado reactivo con signals y observables
- routing y guards
- formularios reactivos
- autenticación y validaciones
- despliegue de una aplicación Angular

## Ejecución local

```bash
npm install
npm start
```

Luego abrir:

```text
http://localhost:4200/
```
